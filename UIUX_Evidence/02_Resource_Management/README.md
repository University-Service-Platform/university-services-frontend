# 02. Resource Management UI/UX Evidence (USMG6-116)
**Group 6 Frontend — University Services Platform**

This directory contains the complete design handoff and evidence files for **USMG6-116: Design Resource Management UI/UX**.

### Directory Structure:
1. [`resource_list_design.md`](./resource_list_design.md) — Screen hierarchy, filter toolbar, responsive card layouts, and action triggers.
2. [`resource_details_modal.md`](./resource_details_modal.md) — In-depth details modal information architecture, metrics grid, amenities, and policy callouts.
3. [`resource_form_specification.md`](./resource_form_specification.md) — Create and Edit resource form schema, input types, and required constraints.
4. [`validation_and_states.md`](./validation_and_states.md) — Form validation matrix, error messaging, and comprehensive designs for loading, empty, and error states.
